# Asena UI

Asena is a pet-care ecosystem covering veterinary care, clinics, appointments, pharmacy, marketplace shopping, pet health tools, Autoship, emergency services, and education.

## Design direction

Keep interfaces trustworthy, calm, warm, premium, modern, professional, and approachable. Prioritize usability over decoration.

Avoid generic AI-generated SaaS aesthetics: excessive glassmorphism, gradients or gradient text, giant rounded cards, heavy shadows, unnecessary icons, decorative UI, excessive animation, huge headings, and card-heavy layouts without purpose.

## UX requirements

- Establish a clear hierarchy and obvious primary action.
- Provide intentional spacing plus useful empty, loading, error, and success states.
- Minimize unnecessary steps and reuse existing components and patterns.
- Keep buttons, inputs, cards, navigation, dialogs, badges, alerts, appointment, doctor/clinic, and product UI visually consistent.

## Accessibility and responsive behavior

Use semantic HTML, keyboard-accessible controls, visible focus states, sufficient contrast, and meaningful labels. Treat mobile as a first-class experience; check mobile, tablet, and desktop behavior before finishing rather than merely shrinking desktop layouts.

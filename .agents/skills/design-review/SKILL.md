# Design Review

Review changed interfaces as a senior product designer. Check whether the primary action is obvious, hierarchy and spacing are clear, typography is readable, the interface feels like Asena, mobile layouts work, and loading, empty, error, and success states are handled.

Check interactive elements for keyboard access, visible focus, labels, and adequate contrast. Ensure healthcare-related interactions are clear and trustworthy.

Fix important issues you find, keeping changes local and proportional. Do not redesign unrelated parts of the application.
